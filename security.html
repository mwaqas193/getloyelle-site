Security and data handling

How Loyelle protects the data merchants trust it with, how long that data is kept and what we do if something goes wrong.

How Loyelle is built

  • Inside Shopify. The app runs embedded in the Shopify admin and signs merchants in with Shopify session tokens. There are no separate Loyelle passwords.
  • Verified messages. Every webhook from Shopify is checked against its signature before it is processed, and webhooks we send to merchants are signed.
  • Separated stores. Every record belongs to one store, and every query is limited to that store.
  • Encrypted in transit. All traffic to and from Loyelle uses HTTPS.
  • Encrypted credentials. Keys for integrations a merchant connects are encrypted before they are stored, and API keys are stored only as hashes.
  • Minimal data. We store names and emails, not phone numbers, addresses or payment details. IP addresses and device identifiers used for referral fraud checks are stored only as one-way hashes.
  • An audit trail. Changes a merchant's team makes to points, tiers and settings are recorded with who made them.

Data retention

We keep personal data only as long as it is needed to run the merchant's loyalty program.

  • Raw copies of Shopify webhook messages are emptied automatically after 30 days.
  • A customer's personal data is removed when Shopify sends an erasure request or the customer is deleted in Shopify.
  • Store access tokens are deleted immediately on uninstall.
  • All personal data for a store is removed when Shopify sends the store erasure request, 48 hours after uninstall.

The full table is in our privacy policy.

Access by our team

  • Access to production systems is limited to the people who need it to run the service.
  • Accounts with that access use strong, unique passwords.
  • Test and development work uses separate systems that hold no real customer data.

Security incident response

This is the process we follow when we suspect that personal data has been accessed, lost or changed without authorisation.

  1. Identify. Anyone who notices a possible incident reports it at once to the incident lead. We record when it was found and what is known.
  2. Contain. We stop the cause first: revoke the affected credentials, rotate secrets, block the route in, and take the affected part of the service offline if needed.
  3. Assess. We work out which stores and which kinds of data are affected, and how many people.
  4. Notify. We tell affected merchants without undue delay, and within 72 hours of becoming aware, with what happened, what data is involved and what we are doing. We notify Shopify as its partner rules require.
  5. Recover. We fix the weakness, restore from a clean state where needed and confirm the service is safe before bringing it back.
  6. Review. Within two weeks we write up the cause, the timeline and the changes made to prevent a repeat.

Report a problem

If you believe you have found a security problem in Loyelle, write to hello@getloyelle.com. We will acknowledge your report within three working days.
